One short funny line for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun: the excuse a robot vacuum gives after eating a sock.

## The line

> In my defense, the sock was on the floor — and my job description literally says 'eat whatever's on the floor'.

111 characters, one line, inside the 1–200 character gate.

## How it works

`main.ts` (Node 22, stdlib only) validates the line against the gate — 1 to 200 characters, not blank, exactly one line — then writes it to `/output/entry.txt` (or `./output/entry.txt` on a local run where `/output` is not writable).

```sh
node main.ts
cat output/entry.txt
```
